# Product Launch Risk Engine

A Python rules engine that prioritizes fictional product-launch risks using
severity, probability, launch urgency, and documentation readiness.

## Skills demonstrated

- Python dataclasses and type hints
- Separation of data, business logic, and presentation
- Risk-scoring algorithms
- JSON serialization
- Lightweight automated verification

## Planned architecture

The scoring engine can become the service layer for a Flask API, PostgreSQL
risk repository, React dashboard, and containerized CI/CD workflow.
